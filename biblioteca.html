CONSULTA RÁPIDA

Glossário
sem mistério.

Termos que aparecem quando falamos sobre proteção na internet.

Autenticação em dois fatores +

Uma confirmação adicional à senha, como um código temporário ou uma chave de acesso, para dificultar entradas não autorizadas.

Malware +

Software criado para executar ações indesejadas, como roubar informações, espionar ou danificar arquivos.

Phishing +

Tentativa de enganar alguém com mensagens ou páginas falsas para obter dados ou induzir uma ação.

Engenharia social +

Uso de manipulação psicológica para convencer alguém a revelar informações ou realizar uma ação que favorece o golpista.

Vazamento de dados +

Exposição não autorizada de informações pessoais ou organizacionais, por incidente, erro ou acesso indevido.
